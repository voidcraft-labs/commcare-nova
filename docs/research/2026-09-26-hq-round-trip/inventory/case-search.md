# Case search

Part of the surface inventory of the HQ round-trip research. Section names in quotes and defect numbers refer to the main document, [`../README.md`](../README.md). Rows that point elsewhere with `→` name the section that owns the item; the inventory [`README.md`](README.md) says which file holds each section.

## Case search

Case search as a whole needs SYNC_SEARCH_CASE_CLAIM plus the target's `CaseSearchConfig.enabled` (both target preconditions; no API reads the configuration, and Nova's existing runtime probe, `lib/commcare/client.ts::probeCaseSearchRuntime`, finds case search off from `/phone/search/`'s plain-text 404; with SYNC_SEARCH_CASE_CLAIM off the answer is HQ's page 404, which it reports as unverified). A module offers search when it has ≥1 search property or default filter (`util.py::module_offers_search`).

### CSQL in `_xpath_query` values and ancestor-path criteria (`case_search/filter_dsl.py`)

A default filter's value is XPath evaluated on the device into CSQL text; HQ compiles that text. Rows are CSQL constructs.

| HQ item | Disposition | Web Apps / Android | Emission |
|---|---|---|---|
| `and`, `or`, parentheses | **HELD**: Predicate `and`/`or` | RUNS / RUNS | same |
