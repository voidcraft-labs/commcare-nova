title: Claude Code plugin
description: Use the Commcare Nova plugin to build CommCare apps from inside Claude Code.
---

The Commcare Nova plugin connects Claude Code to your Commcare Nova account. Once it's installed and signed in, you can ask Claude to build a new CommCare app, modify an existing one, or push an app to CommCare HQ. Claude does the work using your Claude Code plan; Commcare Nova doesn't bill anything on top.

## Pages in this section

- [Quick start](./quickstart.mdx): install the plugin, sign in, and build your first app.
- [Commands](./commands.mdx): reference for every `/nova:*` command.
- [Manage access](./access.mdx): disconnect Claude Code from Commcare Nova or uninstall the plugin.
