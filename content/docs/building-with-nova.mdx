---
title: Building an app with Nova
description: How Nova turns a conversation into a reviewed, working app and how to resume unfinished work.
---

## From a description to an app

When you describe a new app in chat, Nova builds a complete private version of
the app: its records, workflows, forms, fields, lists, access, navigation, and
outside setup. It uses the same app-building operations available in Nova after
the app exists, while keeping this work private. An independent review checks
the exact working app before anything becomes visible. Nova asks questions only
when an answer materially changes the app or isn't safe to assume.

The live status immediately above the chat box names the current phase. Nova
also gives a conservative rough estimate based on the design's assigned effort
level: about 30 minutes for compact designs, an hour for standard designs,
and 90 minutes for extended designs. Internal design submissions and technical
review details stay out of the conversation.

No placeholder or partial app appears while that work is underway. The first
app you see is the complete reviewed version, created in one step. The builder
stays read-only around the build progress until then, so you never edit
underneath the initial build. Unfinished private work never appears in Preview
or the app tree.

## Resume an unfinished design

An unfinished app design appears under **Designs in progress** on the app list.
Choose **Resume** to return to the same conversation and continue from its
saved stage. Choose **Discard** when you no longer want Nova to take that
design further.

Nova saves each accepted app-building operation as it works. If the connection,
server process, or model context is interrupted, it reconstructs the exact
private app from those operations instead of relying on chat memory or
rewriting completed sections. Review and publication are bound to that exact
version, so neither can silently omit part of the candidate.

The design also has its own recovery address as soon as the first chat turn
starts. Refreshing the page returns to that design. If the app was created while
an update was lost in transit, Nova opens the authoritative app instead of
starting a second copy.

## If review still finds a problem

Nova corrects blocking review findings against the saved private app and asks
the reviewer to verify those exact changes. If verification still finds a
blocking problem, the design pauses instead of repeatedly guessing. Choose
**Continue** to let Nova make another focused correction from that same saved
app. Other messages cannot redirect a build while construction is active.
Temporary provider, connection, and database interruptions recover
automatically.

## Start with a blank app

Choose **Start with a blank app** when you want to begin directly in the
builder. That path creates Nova's smallest valid Survey, Form, and Question
starter immediately, without the reviewed conversational design flow.

## External setup

Some workflows depend on work outside the app, such as loading Project data,
providing an existing media asset, or configuring an automation in CommCare
HQ. Nova names those prerequisites and never claims that it completed them.
Preview does not pretend to run external automations. One design session builds
one app in your current Project; if a request describes several apps, Nova asks
which one to build first.
