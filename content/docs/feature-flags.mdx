Some commcare nova app features are being introduced gradually in CommCare HQ.
Before workers can use one, it needs to be enabled for the CommCare HQ project
space that will host your app. This setting is called a **feature flag**, and
Dimagi Support can enable it for you.

The Publish window tells you when your app needs one. Seeing a feature flag
doesn't mean the app is broken. It means the destination project space needs
access to that feature before you roll the app out to workers.

<Callout type="info">
Feature flags belong to a CommCare HQ project space, not to an app file. If you
publish the same app to another project space, that space needs its own check.
</Callout>

## What you'll see when you publish

### Uploading directly to CommCare HQ

In the Publish window, choose **CommCare HQ** under **Publish option**, then
choose the destination project space. Nova checks that space and tells you
whether the feature flags your app needs are enabled there.

- If everything is enabled, you're ready to continue
- If a flag isn't enabled, the notice names it and links to its guide. The guide
  includes the support details Dimagi needs
- If CommCare HQ can't complete part of the check, the notice marks the result
  as unconfirmed instead of saying that the flag is off

You can refresh the check at any time. The Publish window also checks again
after a successful upload, so the final message reflects the project space that
received the app.

### Downloading an app for later

Under **Publish option**, choose **CommCare HQ app file** or **CommCare mobile
app file**. Because a downloaded file isn't connected to its eventual project
space, the Publish window can tell you which flags the app needs, but it can't
tell whether those flags are already enabled there.

In this case, the list means **these flags need to be enabled in the destination**.
It doesn't mean they were checked and found missing.

## Ask Dimagi Support to enable a flag

To get a flag enabled, email [support@dimagi.com](mailto:support@dimagi.com)
with:

- The name of the CommCare HQ project space where the app will live
- The feature flag names shown in the Publish window. Open each linked guide to
  find its support code
- A note that you're publishing an app from commcare nova

You don't need to change the app or find a hidden setting in CommCare HQ.
Dimagi Support can enable the flag for the project space you name.

An app may upload successfully while a required flag isn't enabled. Until it's
enabled, workers may not see the feature or may get an error when they try to
use it.

Feature flags are different from paid plan features and account permissions.
The Publish window checks the flags on this page. It can't inspect every paid
plan feature or worker permission in the destination project space.
