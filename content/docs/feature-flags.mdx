title: Feature flags
description: What CommCare HQ feature flags are, which Nova features use them, and how to get them enabled for a project space.
---

A feature flag is a switch that Dimagi controls for one CommCare HQ project
space. It lets that space use a feature that is not yet available everywhere.
You do not turn these switches on inside Nova or in the ordinary CommCare HQ
settings.

An agent connected to Nova can call `get_app_hq_feature_flags` before
publishing. The result includes only the CommCare HQ flags the app currently
uses, the app setting that caused each requirement, a plain-language
explanation, and the public link for that flag. Without a project space, it
reports requirements without claiming they are off. When the agent supplies
one of your connected project spaces, the same tool checks that exact space and
separates flags confirmed missing from checks HQ could not answer. The agent
can pass those details to you or include them in an existing deliverable
without first publishing the app or loading this page.

Your Nova app can still be complete and upload successfully when a required
flag is off. The problem appears later: a worker may not see the expected
behavior, or a feature such as case search may fail when they try to use it.
That is why Nova reports these requirements before and at publish time.

## What to do

When you open Publish, Nova shows the flags the app requires before you take an
action. For a connected CommCare HQ project space, Nova checks that space right
away; you can refresh the check, and Nova checks again after upload. A
downloaded JSON, ZIP, or CCZ file has no connected destination, so the Web and
Mobile tabs instead list the flags that the eventual destination needs before
you download. That list does **not** mean Nova checked and found them off.

If a required flag is missing, email
[support@dimagi.com](mailto:support@dimagi.com). Include:

- the CommCare HQ project space name;
- each feature flag name and code that Nova listed; and
- a short note that the app was published from CommCare Nova.

Flags apply to a project space, not to the app file. Importing the same file
into a different space means that space needs its own flags checked.

## Feature flags Nova uses

<FeatureFlagCatalog />

Advanced Case Search is a child of Simple Case Search in CommCare HQ. When an
app needs the advanced flag, Nova lists both so the support request is complete.

<Callout type="info">
Feature flags are different from paid plan features and account permissions.
Nova's publish check covers the flags on this page; it cannot inspect every
subscription privilege or worker permission in the destination space.
</Callout>
